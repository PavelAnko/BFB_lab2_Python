Propose interaction patterns between a manager thread and a fixed pool of worker threads (scaled to the number of available CPU cores) to avoid the overhead of creating a new thread for each pair. Compare possible mechanisms for distributing unprocessed element indices among idle worker threads and synchronization methods between waves that guarantee the next wave starts only after the current one is completely processed.

Propose approaches to optimize index distribution from the manager thread to worker threads at a scale of 1,000,000,000 elements so that per-pair synchronization overhead does not degrade performance. Additionally, suggest ways to verify the algorithm on a test array [1, 2, 3, 4, 5, 6] by outputting intermediate wave states, along with methods for benchmarking execution time on the full dataset.
